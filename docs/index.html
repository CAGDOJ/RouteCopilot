Perguntas frequentes

O pagamento é por assinatura?

Não. O modelo inicial é por créditos de rota. Cada nova AT validada utiliza um crédito.

Aceita cartão?

Não. O modelo comercial definido para esta versão usa somente PIX.

O mapa abre o Waze?

O mapa principal é interno. O Waze é uma opção separada para quem quiser navegação externa.

O RouteCopilot substitui o SPX?

Não. Ele é auxiliar. Login, autenticação e registro oficial de Entregue/Ocorrência permanecem no SPX.
