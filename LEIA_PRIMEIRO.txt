RouteCopilot V4.1 - pacote corrigido

CORRECAO PRINCIPAL
A V4 anterior podia falhar se APLICAR_ATUALIZACAO.ps1 fosse colocada dentro
da propria pasta do projeto, pois tentava copiar app\ para ele mesmo.

Nesta versao, os arquivos da atualizacao ficam isolados em:
    payload\

Assim, o script sempre copia de payload\ para o projeto e evita
origem=destino.

USO
1. Extraia este ZIP em uma pasta separada, por exemplo:
   C:\Users\stel-adm\Downloads\RouteCopilot_V4_1

2. Abra PowerShell dentro dessa pasta.

3. Execute:
   powershell -ExecutionPolicy Bypass -File .\APLICAR_ATUALIZACAO.ps1 -ProjectPath "C:\Users\stel-adm\Documents\GitHub\RouteCopilot"

4. Depois:
   cd C:\Users\stel-adm\Documents\GitHub\RouteCopilot
   .\gradlew.bat clean
   .\gradlew.bat assembleDebug
